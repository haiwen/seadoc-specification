# Subtitle

`subtitle` is a block element node that represents a document subtitle.

## Children

- Its `children` directly contain [text nodes](text.md) and supported inline elements, such as [links](link.md). Content following a subtitle remains in sibling blocks, rather than becoming its children.

## Data Structure

```json
{
  "id": "G1opTnrHRr6aX7qbJXZJiw",
  "type": "subtitle",
  "children": [
    {
      "id": "D_bLOntqQHSZ8lu9VJn_JQ",
      "text": "subtitle content"
    }
  ]
}
```
