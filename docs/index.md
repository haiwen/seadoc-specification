# Introduction

SeaDoc Specification describes the `.sdoc` document format and the data structures of supported nodes. Each node reference explains its fields, child structure, and examples.

## Reading Order

1. Start with the [SeaDoc Document Model](support-types.md) to understand the file format, node hierarchy, and common fields.
2. Read [Text](data-structure/text.md) for text leaves and formatting marks.
3. Explore **Block Elements**, starting with [Paragraph](data-structure/paragraph.md) and [Heading](data-structure/header.md), then follow the references for lists, containers, and other blocks.
4. Explore **Inline Elements** for [Link](data-structure/link.md), [Image](data-structure/image.md), [File Link](data-structure/file_link.md), and [SeaDoc Link](data-structure/sdoc_link.md).
